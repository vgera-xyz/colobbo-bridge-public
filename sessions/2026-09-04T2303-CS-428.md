## Defects found, and who wrote them

Seven. Six were checks that looked right and found nothing. Three were mine, in
this session — recorded because the pattern matters more than the count:

1. `test-eval-seal.sh` 31% flake — `':3'` matched the ISO timestamp.
2. Two suites green on macOS, never in CI (BSD `sed`, `$PWD`/`$HOME` guard).
3. Graphify no-op — sentinel downstream of the bug.
4. **Mine** — a vacuous differential: a full URL passed where the harness wanted a
   path; five empty captures compared as "unchanged". Two further tamper attempts
   failed before a real 401 emitter proved detection.
5. **Mine** — fake outage tests: `makeCognitoStatuses({})` throws
   `UserNotFoundException` per email, which models *every user deleted*, not an outage.
6. **Mine** — `TS_LIB` hardcoded to this laptop; 14 Tier B assertions never ran in
   CI and the suite reported `passed 83, failed 0`.
7. The `no()` helper was undefined, so an assertion never ran and the suite reported
   101 passed. This is what Gate 25 exists for.

One claim I made was simply wrong and is corrected here: a trailing `echo` does
**not** swallow a verdict in GitHub Actions, because Actions runs `run:` blocks as
`bash -e {0}`. The swallow shape was two-for-three, not three-for-three.

## What is NOT done — item 2, in the operator's order

Unstarted, and specified. It must exist **before the next ticket runs** or the
measurement is lost.

- **2a (build first)** — a run aggregator over `run.json` across all runs: runs-to-PR
  per ticket, which gate failed, defect class, **plus escape-hatch usage per run**
  (`ALLOW_TEST_SKIPS`, `ALLOW_NON_ADDITIVE`, any force path). Individually each hatch
  is fine; what nobody can currently see is **accumulation** — a hatch used every run
  has stopped being an exception. Recommend where it lives and what it records.
- **2b** — audit every `FAIL:` message for whether it names what was actually
  checked. Two known liars (the git-push/branch-collision message and the
  typescript-resolution message) cost extra runs this session.
- **2c** — recommend whether a failed run files its own record, and on which surface
  (Linear / #colobbo-radar / filesystem), with reasoning.

**Constraint, operator-stated and agreed: do NOT build auto-diagnose-and-repair.**
Six of seven defects were checks that looked right and found nothing; an agent
repairing its own verification machinery unsupervised is the wrong thing to add to
that. Memory before autonomy.

The 2a case in miniature: `ALLOW_NON_ADDITIVE` was used once this session,
defensibly — and nothing would have shown that to the next session.
