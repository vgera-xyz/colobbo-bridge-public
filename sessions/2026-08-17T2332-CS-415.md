## Summary

**Discovery-only session** (no fixes, no commits to product repos, no PRs) in the `discovery-ci-security` worktree: a read-only fleet-wide CI/security gate inventory across web-angular, api_node, Colobbo-Mobile + the shared `github-actions/` source, grounded entirely in origin refs, live `gh api` queries, and file reads. Output = a published discovery **artifact** + a **CS-415 plan tree** (parent + 3 session sub-issues). The operator supplied the tooling + rollout decisions mid-session; those are encoded verbatim in the tickets.

The load-bearing findings corrected several stale premises from the CS-50-era notes:

- **Colobbo-Mobile has zero enforced PR gates** — no branch protection, no rulesets (beyond the org tag rule), no required checks on any branch, and no typecheck/lint/test/build workflow at all. A PR can merge with nothing green. → CS-417.
- **Snyk has no footprint anywhere in the org** — no token, no `.snyk`, no workflow ref, no GitHub App (org apps: codecov, sentry, cursor, linear, claude, railway-app, seer-by-sentry). The "move Snyk off the personal `vgera-xyz` org" premise is stale; Snyk→osv is a greenfield add, not a removal. → CS-416.
- **GitHub Advanced Security is DISABLED on all three private repos** — `code_security`, `secret_scanning`, `secret_scanning_push_protection` all off. So CodeQL / native secret scanning / push protection are one paid licensing decision, not free toggles. CodeQL has run exactly once ever (Mobile, default-setup, 2026-08-13).
- **Dependabot auto-fix PRs off on all three** (alerts on everywhere; only web-angular has a `dependabot.yml`).
- **api_node dynamic-SQL injection surface** — user-controlled `filterCriteria` from `req.query` (8+ controllers) reaches SPs that embed it into a dynamic WHERE (`skill.service.ts:10-14`), defended only by an incomplete character denylist `sanitiseLike()`. Systemic per the COL-186 census. → CS-418.
- **Workflow fleet is copy-paste** — `ai-review.yml` in three divergent versions (697/503/138 lines), `diff-coverage.mjs` duplicated with drifted flags, branch names hardcoded. → CS-416 consolidation.

## Operator decisions (locked this session)

- **Tooling — license-free (no GHAS):** Gitleaks (blocking PR gate fleet-wide) + TruffleHog (weekly full-history scan) + Semgrep (SAST, typed rulesets) + osv-scanner (deps). GHAS both SKUs DEFERRED, re-open trigger = **WHA / Essential Eight or SOC 2 evidence**.
- **Rollout — ratchet with one exception:** Semgrep + osv advisory → fix backlog → blocking; **Gitleaks blocks day one** (new-diff only, no backlog); TruffleHog first full-history run is triage-only → rotation list, not a gate.
- **Gate tiering (should-all-be-required = NO):** Tier-1 required (fast+deterministic+security-critical), Tier-2 scheduled (Stryker/CodeQL/DAST/k6), Tier-3 advisory (AI review/Lighthouse/spec-naming).
- **Design constraints (standing, saved to memory):** reusable `workflow_call` engine in `github-actions/`; zero-hardcode (thresholds via org variables, per-repo via `inputs:`); branch-agnostic (`github.base_ref`); repo-type-aware gate selection.
